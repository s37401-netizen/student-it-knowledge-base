Zasady pracy z GIT

Polecenia GIT
PolecenieZnaczenie
git clonePobranie repozytorium i utworzenie lokalnego katalogu.
git statusSprawdzenie gałęzi oraz plików zmienionych i przygotowanych.
git addDodanie konkretnego pliku do obszaru staging.
git commitZapis przygotowanych zmian z czytelnym komunikatem.
git pushPublikacja nowej gałęzi i ustawienie śledzenia.
git pullPobranie zmian bez tworzenia nieoczekiwanego merge commita.
git fetchPobranie informacji o zmianach bez modyfikowania plików roboczych.
git branchWyświetlenie lokalnych gałęzi i oznaczenie aktywnej.
git switchPrzełączenie się na inną gałąź.
git logSkrócony podgląd pięciu ostatnich commitów.

Procedura pracy

  1. Przejdź na branch main i pobierz najnowszy kod: git switch main, git pull
  2. Utwórz i zmien na nowy branch: git switch -c nazwa
  3. Wprowadź i sprawdź zmiany w plikach
  4. Przygotuj pliki i zapisz zmianę: git add (plik), git commit -m "opis zmian"
  5. Wyślij branch: git push -u origin nazwa
  6. Otwórz Pull Request z nowego brancha do main i poproś o review
